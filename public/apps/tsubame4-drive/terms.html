Purpose and operator

TSUBAME4 Drive Storage is a personal file storage utility operated by Taishiro Wakamiya. It connects an authorized Google Drive account to the owner's TSUBAME4 environment using google-drive-ocamlfuse. These terms describe the intended use of this individually operated setup.

Authorized use

Use is limited to the owner and any users expressly authorized by the owner and the relevant infrastructure providers. Users must have permission to access and store the files they handle and must follow applicable Google Drive and TSUBAME4 usage rules.

File operations and responsibility

Writes, renames, and deletions performed through the mount affect the connected Google Drive account. Users should protect credentials, retain appropriate backups, verify completed transfers, and avoid conflicting simultaneous edits through multiple clients.

The mount is a network filesystem. API limits, authentication expiry, connectivity, cache space, node restarts, and provider availability can interrupt operations. Users are responsible for checking the mount and transfer state before relying on stored files.
